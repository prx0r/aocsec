# Passwords, 2FA, offboarding, insurance — the unglamorous package

> Highest ROI per minute in business security. Free tools, one session,
> verified on the spot. Part of every onboarding, not an upsell.

## 1. Password manager (Bitwarden, free)

- Install Bitwarden (free tier is enough). One strong master password,
  written on paper, stored off-phone.
- Move every business login into it. Kill password reuse — one breach
  anywhere replays everywhere otherwise.
- Verify on the spot: log out and back in once using only the manager.

## 2. 2FA order (email first, always)

Email is the master key — every password reset flows through it.

1. Email account 2FA on (authenticator app, not SMS where avoidable).
2. Bank + accounting 2FA on.
3. Social/business pages 2FA on.
4. Recovery codes printed and stored off-phone (see device checklist:
   losing phone + codes = locked out of everything).

## 3. Offboarding (every team change)

When anyone with access leaves (employee, subcontractor, agency):

- [ ] Remove from email/Google Workspace users or change shared passwords
- [ ] Remove from job software (Tradify/ServiceM8/etc.)
- [ ] Remove from WhatsApp groups and shared chats
- [ ] Remove from social page admin roles
- [ ] Collect keys, alarm codes changed if they held them
- [ ] Review bank mandate/signatories if applicable

Five minutes. Never done without a checklist — which is why it's here.

## 4. Insurance pointer (flag, don't advise)

- Ask: does professional indemnity cover AI-assisted work errors?
  Most traditional policies were written before this existed.
- Cyber cover for a 2-person trade firm is usually disproportionate;
  the controls in this package are the proportionate answer.
- We are not insurance advisers. Raise the question, record the
  answer, move on.
